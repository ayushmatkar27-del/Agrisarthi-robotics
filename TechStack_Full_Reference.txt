1. FRONTEND WEB APPLICATION
================================================================================

Technology         | Version  | Where Used & Why
-------------------|----------|--------------------------------------------------
React 19           | ^19.0.0  | Core UI framework. Powers components across the
                   |          | website — Navbar, Hero, Fleet showcase, Mission
                   |          | Control HUD, ROI Calculator, Pricing, Contact
                   |          | form, and all interactive modal overlays.
                   |          |
React Router DOM 7 | ^7.3.0   | Multi-page client-side router. Manages 5 dedicated
                   |          | page routes: Home (/), Rovers (/rovers), Mission
                   |          | Control (/mission-control), Services (/services),
                   |          | and About (/about). Clicking the AgriSarthi logo
                   |          | instantly navigates to Home (/). Includes
                   |          | ScrollToTop on route changes.
                   |          |
Vite 6             | ^6.2.0   | Build tool & dev server. Provides instant HMR
                   |          | (Hot Module Replacement) during development and
                   |          | fast production bundling with tree-shaking. Runs
                   |          | on localhost:3000 for local development.
                   |          |
@vitejs/plugin-    | ^4.3.4   | Enables JSX transformation and React Fast Refresh
react              |          | inside Vite. Applied in vite.config.js.
                   |          |
TailwindCSS 4      | ^4.3.3   | Utility-first CSS framework. Used across EVERY
                   |          | component for rapid styling — 5-zone gamut colors,
                   |          | responsive breakpoints (sm/md/lg/xl), spacing,
                   |          | typography, flex/grid layouts, border-radius,
                   |          | shadows, and glassmorphism effects.
                   |          |
@tailwindcss/vite  | ^4.3.3   | TailwindCSS v4 Vite plugin. Integrated in
                   |          | vite.config.js to compile Tailwind styles via
                   |          | the `@import "tailwindcss"` directive in
                   |          | index.css.
                   |          |
Lucide React       | ^1.16.0  | Icon library. Provides 100+ crisp SVG icons used
                   |          | throughout the website for: navigation items
                   |          | (Bot, Phone, Menu), sensor indicators (Droplets,
                   |          | Activity, Eye, Radio), action buttons (Play,
                   |          | Sparkles, ArrowRight), and section headers
                   |          | (Award, Layers, Cpu, Shield).
                   |          |
Canvas Confetti    | ^1.9.4   | Used in the BookDemoModal component to trigger
                   |          | a celebratory confetti animation when a user
                   |          | successfully completes the 3-step demo booking
                   |          | form.

6. ROVER HARDWARE TECH STACK (Physical Prototype)
================================================================================

Layer              | Technology                   | Where Used
-------------------|------------------------------|-----------------------------
Primary Brain      | Raspberry Pi 4 (4GB LPDDR4)  | Runs YOLOv8n inference,
                   |                              | OpenCV row-following,
                   |                              | video streaming, and
                   |                              | WebSocket communication.
                   |                              |
Co-Processor       | ESP32 Dual-Core 240MHz       | Motor PWM control, sensor
                   |                              | ADC reading loops, battery
                   |                              | voltage monitoring, and
                   |                              | LoRa/Wi-Fi telemetry.
                   |                              |
AI Model           | YOLOv8n (Ultralytics Nano)   | Edge object detection on
                   |                              | Pi 4 CPU. Detects humans,
                   |                              | animals, pests, obstacles.
                   |                              |
Vision Library     | OpenCV (Python)              | Path-following algorithms,
                   |                              | image preprocessing, and
                   |                              | bounding box rendering.
                   |                              |
Motor Control      | L298N / BTS7960 H-Bridge     | Drives 4x DC geared motors
                   |                              | with variable speed PWM
                   |                              | from ESP32 GPIO pins.
                   |                              |
Sensors            | Capacitive Soil Moisture     | Analog soil moisture via ADC
                   | DHT22 Temp & Humidity        | Digital temp/humidity sensor
                   | MQ-2 Gas Sensor              | Analog gas concentration
                   | Sound Level Sensor           | Decibel ambient noise
                   | PIR Motion Sensor            | Night-time intruder detect
                   | HC-SR04 Ultrasonic (x3)      | Obstacle distance (2-400cm)
                   |                              |
Camera             | Pi Camera V2 / USB HD 120°   | Live video stream, YOLOv8
                   |                              | input feed.
                   |                              |
Battery            | 12V 6.0Ah LiFePO4 / Li-Ion   | Main power with 3S BMS for
                   |                              | overcharge and over-discharge
                   |                              | protection.
                   |                              |
Solar Panel        | 25W Monocrystalline          | Optional trickle charging
                   |                              | via foldable panel.
                   |                              |
Connectivity       | LoRa SX1278 (433MHz Mesh)    | Long-range field telemetry
                   | SIM7600 4G LTE               | Cloud data uplink
                   | Wi-Fi 802.11 b/g/n           | Local AP mode for direct
                   |                              | laptop/phone dashboard.
                   |                              |
Chassis            | 4WD Rocker-Bogie Suspension  | All-terrain frame with
                   |                              | 120mm ground clearance.
                   |                              | 460mm x 380mm x 290mm.
