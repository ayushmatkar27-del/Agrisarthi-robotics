2. GLOBAL UI PATTERNS & DYNAMIC SCROLL ANIMATIONS
================================================================================

Dynamic Scroll-Triggered Content Reveal & Pop System:
  Inspired by modern robotics platforms (e.g. OTTO Motors), the application uses
  a custom IntersectionObserver-powered animation engine (`ScrollReveal.jsx`):
  • Scroll-Triggered Pop & Spring:
    Cards, headlines, and data panels pop into place (`scale-[0.90] → scale-100`,
    `opacity-0 → opacity-100`, `translate-y-6 → translate-y-0`) as the user scrolls.
  • Staggered Cascade:
    Sibling cards pop sequentially with 80ms to 200ms delays (`delay={index * 80}`).
  • Directional Sliders:
    Supports `slide-left`, `slide-right`, `slide-up`, and `pop` animations with
    hardware-accelerated `cubic-bezier(0.16, 1, 0.3, 1)` easing curves.

Glassmorphism Panels (Light Farming Theme):
  Panels use frosted-white glass styling with backdrop-blur (16px),
  semi-transparent white backgrounds, and thin green-tinted borders:
    .glass-panel       — White frost (82% opacity), subtle green border
    .glass-panel-glow  — White frost (90%) + emerald border + green glow
    .glass-card        — White frost (78%), hover-lift (translateY -2px)
                         with emerald border highlight on hover

Micro-Animations:
  • Ping dots (animate-ping) on live status indicators
  • Pulse glow (animate-pulse-glow, 3s cycle) on rover schematics
  • Hover translateY shifts on all interactive cards
  • Smooth scroll behavior (scroll-smooth on <html>)
  • Border color transitions on card hover (transparent → emerald)
  • Scale-up on active tab buttons (scale-105)

5. STATE MANAGEMENT & DATA FLOW
================================================================================

App.jsx manages all global state and passes data down via props:

  App.jsx (Root)
    ├── liveTelemetry state (updates every 2.5s via setInterval)
    │     Values: battery, signal, speed, moisture, temp, humidity,
    │             gas, sound, distance
    │     Consumed by: Hero, MissionControlDemo
    │
    ├── fleetStats state
    │     Values: activeRovers, totalAcres, latency
    │     Consumed by: LiveStatusTicker
    │
    ├── isDemoModalOpen state
    │     Toggled by: handleOpenDemoModal / onClose
    │     Controls: BookDemoModal visibility
    │
    ├── preselectedRover state
    │     Set when "Book Demo" clicked with rover ID
    │     Passed to: BookDemoModal (pre-selects rover in step 1)
    │
    └── handleNavigate function
          Smooth-scrolls to any section by element ID
          Passed to: Navbar, Hero, Footer

9. MOBILE USER EXPERIENCE & RESPONSIVE DESIGN SPECIFICATION

9.1  MOBILE NAVIGATION & BRAND IDENTITY
     • Compact Header: On mobile viewports (< 640px), the "CONTACT US" button
       is concealed from the top header to ensure the brand logo and search icon
       have generous breathing room.
     • Sliding Navigation Drawer: Clicking the animated hamburger icon triggers
       a backdrop-blurred top-down drawer (#0a0f0d/98) featuring:
       - 5 full-width route links with subtle trailing arrow indicators.
       - High-contrast green pill CTA ("CONTACT US →") with smooth scroll to contact form.
       - Distinct bordered CTA ("BOOK PILOT DEMO →") opening the 3-step trial modal.

9.2  ADAPTIVE "WHY AGRISARTHI ROVERS" INTERACTIVE STEPPER
     • Desktop Mode (>= 1024px): Pinned 340vh sticky viewport. As user scrolls down,
       progress bar fills and features 01 -> 02 -> 03 -> 04 cycle smoothly while
       the live telemetry graphic dynamically updates.
     • Mobile Mode (< 1024px): Switches to height: auto with full vertical overflow.
       Features 01 to 04 are presented as tap-to-expand interactive cards.
       Tapping any card immediately reveals its full engineering description and
       synchronizes the live telemetry card above it without scroll trapping.

9.3  DUAL-ENGINE MISSION CONTROL ON MOBILE
     • Default HUD Routing: /mission-control lands directly on the 2D live telemetry
       dashboard without intermediate redundant subheaders.
     • Touch Steering Pad: 4-way direction buttons designed with ergonomic finger
       spacing for teleoperation on smartphones.
     • 1-Click 3D WebGL Simulation: Prominent glowing green button enables instant
       switch to the 3D Farm Field simulation, featuring a dedicated "Telemetry HUD"
       return button.
